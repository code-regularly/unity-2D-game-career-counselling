## Career Counselling Game

This project has been implemented in Unity 2D gaming engine and C# programming language. It was the firt-ever, ever, exposure I had to Unity game development. 

### Project Timeline

I built this project back in 2020 during my Summer break, right after my sopohomore year ended at the university. 

### Project Details

The project helps you choose between:
* Web development & Mobile deelopment
* LAMPP Stack Vs. MERN Stack
* Flutter & Dart Vs. React-Native & JavaScript

It is a very simple game that switches through multiple scenes, gives some developmental advice and encourages CS students to start learning web development or mobile development to hone their skills before graduation.
